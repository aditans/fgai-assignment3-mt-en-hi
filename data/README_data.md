# Data

The IIT Bombay English-Hindi Parallel Corpus is available from:

- Hugging Face: https://huggingface.co/datasets/cfilt/iitb-english-hindi
- Original CFILT page: https://www.cfilt.iitb.ac.in/iitb_parallel/

The full dataset is intentionally not committed. The notebook downloads it with `datasets.load_dataset`, applies the documented filtering, and writes only split metadata and derived evaluation files. Do not commit the downloaded corpus or model caches.
